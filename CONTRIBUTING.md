# Contribuer · Contributing · Contribuir

## Français

Les contributions les plus utiles sont des retours d'éditeurs, PA et cabinets sur un cas d'exception réel anonymisé, un adaptateur indépendant ou un test d'interopérabilité reproductible. Ouvrez d'abord une issue pour proposer un changement de schéma. Décrivez le scénario, les droits nécessaires, les sources des faits et le comportement attendu quand un système refuse l'action. Ne joignez aucune facture réelle, donnée client ou clé d'accès. Tout texte destiné aux utilisateurs doit être fourni en français, anglais et espagnol dans la même contribution. Exécutez `npm test`, `npm run check` et `npm run format:check`.

## English

The most useful contributions are feedback from vendors, approved platforms and accounting firms on an anonymized real exception case, an independent adapter or a reproducible interoperability test. Open an issue before proposing a schema change. Describe the scenario, required permissions, fact sources and expected behavior when a system denies an action. Do not attach real invoices, customer data or access keys. Provide every user-facing text in French, English and Spanish in the same contribution. Run `npm test`, `npm run check` and `npm run format:check`.

## Español

Las contribuciones más útiles son comentarios de proveedores, plataformas autorizadas y asesorías sobre un caso real de excepción anonimizado, un adaptador independiente o una prueba de interoperabilidad reproducible. Abra primero una incidencia antes de proponer un cambio de esquema. Describa el caso, los permisos necesarios, las fuentes de los hechos y el comportamiento esperado cuando un sistema deniega la acción. No adjunte facturas reales, datos de clientes ni claves de acceso. Incluya todos los textos dirigidos a usuarios en francés, inglés y español en la misma contribución. Ejecute `npm test`, `npm run check` y `npm run format:check`.
